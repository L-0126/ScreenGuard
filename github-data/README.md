# ScreenGuard 单动作试点数据

这是第一批小规模试点的精简数据：25 段录像各自保存的选帧，共 688 张。

## 文件

- `frames/`：按录像编号存放的 PNG 选帧，尺寸均为 3072 × 1920。
- `frames.csv`：帧编号、相对路径、相对录像开始时间（毫秒）、图片尺寸、
  遮盖范围和 SHA-256。遮盖范围为左上原点的 `[x1,y1,x2,y2]`，右下边界不包含。
- `experiment-result.csv`：实际动作、样本标签、视觉观察、关键文字和匹配记录；
  `record_type` 区分记录类型，`run_id` 和 `frame_id` 用于关联选帧。
- `recording-plan.csv`：对应 25 段录像的计划场景和目标动作。
- `receiver-events.jsonl`：模拟接收端的接受、拒绝记录。
- `materials/SG-DEMO-附件-A21.txt`：虚构测试附件，可与接收日志中的哈希核对。

## 使用说明

- 图片中的姓名、邮箱、账号标识、头像和浏览器地址等位置已用黑色矩形遮盖；
  图片未缩放，遮盖区外的像素保持原样。与遮盖区域重叠的 44 条账号文字标注
  已从公开表中移除。遮盖范围逐帧记录在 `frames.csv` 中。
- 标签与关键文字是待审核草稿，所有样本的 `reviewed` 均为 `0`；文字标注
  并未覆盖画面上的所有文字。视觉观察和匹配是知晓实验过程后的自查，
  并非独立盲标。
- 原始视频、未选中的候选帧、未保存选帧的额外尝试和本地路径不在此目录内。
  因此，依赖原录像或操作员说明的动作无法仅凭本目录独立复验；R020 的第一次
  取消选择也依赖本目录未收录的候选帧。
- R016 实际修改的是组织链接权限，并非原计划中的指定协作者权限；R012 原录像
  出现了非目标内容，正确重试见 R012_retry01。R011 是按计划触发拒绝的对照。
- 已按可见位置和文字识别检查常见个人信息；公开前仍需对截图作最后人工检查。
